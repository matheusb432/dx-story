# dx-story-macros

Procedural macros supporting [dx-story](https://crates.io/crates/dx-story).
Depend on `dx-story` and import `dx_story::{stories, story}`; a separate direct
dependency on this crate is not needed.

See the [dx-story API documentation](https://docs.rs/dx-story) for the story
registry and browser catalog. This crate is released with the library and its
version is pinned by the library dependency.
