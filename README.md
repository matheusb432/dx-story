# dx-story

[![Crates.io][crates-badge]][crates-url]
[![Docs.rs][docs-badge]][docs-url]
[![MIT licensed][mit-badge]][mit-url]

Dioxus component storybook. Add a render function for each state you want to see,
then browse and interact with them in a browser catalog.

The `dx-story` library provides the registry and catalog. The optional `dx-story-cli` sets
up a catalog in an existing Cargo package and runs it with Dioxus.
